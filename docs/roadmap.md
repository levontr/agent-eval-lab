# Scope

Implemented: the agent, three store tools, local tracing, a three-case runner,
and a separate judge checked against four synthetic examples.

Useful follow-ups, if needed:

- More edge cases and repeated runs.
- Better provenance in experiment reports.
- A hard authorization check before refund execution.
- Independent judge examples, including ambiguous answers and partial evidence.
- A trace viewer for larger experiments.

No automatic judge integration or Google Cloud evaluation service is planned for
this version. The project stays small enough to read end to end.
